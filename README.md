# cococat · 喵呜小屋

一款中文 3D 宠物陪伴小游戏。领养一只小可爱，陪它吃饭、玩耍、换装和探险，把小屋慢慢布置成家。使用 Three.js + Vite，纯前端运行，无需注册。

**[在线试玩](https://leeweir.github.io/cococat/)** · [源码仓库](https://github.com/leeweir/cococat) · [构建与发布](https://github.com/leeweir/cococat/actions/workflows/pages.yml)

## 玩法

- **34 种宠物**：20 种猫、5 种狗、3 种兔，以及刺猬、仓鼠、龙猫、雪貂、荷兰猪和蜜袋鼯，各有外形、性格和偏爱的食材。
- **日常照顾**：搭配猫饭、搓泡泡洗澡，一起看鱼鱼频道、蝴蝶纪录片和鸟鸟音乐会。
- **互动陪玩**：逗猫棒、抛球捡球、纸箱捉迷藏，也可以摸摸小猫、听它喵喵叫。
- **近景陪伴**：摸头、挠下巴、碰鼻子、击掌和慢眨眼，小猫会用不同动作回应。按提示完成三个小心愿，每轮获得爱心 +2、亲密度 +5、心情 +10；完成后可自由互动，也可再陪一轮。
- **100 件免费服饰**：帽子、眼镜、围脖、上衣、裤裙、背饰、鞋袜和尾饰，8 个部位自由混搭，支持随机搭配和一键脱下。领口配饰贴合各品种的胸颈轮廓，围巾垂带、领带和口水巾沿胸前垂落，转头时不会整件抬离身体。小书包随背部坡度倾斜，肩带连接包体并贴合身体，支持与上衣混搭。
- **布置小屋**：摆放家具、切换墙面与地板配色；部分家具用陪玩和寻宝获得的爱心解锁。
- **外出探险**：花花公园、蓝铃花园、月牙小街，收集 12 件宝物，结识猫朋友，遇见随机小故事。
- **每日心愿**：在“日常照顾”中打开“今日心愿”。成功照顾一次、玩完一轮、找到一件宝物后，可领取 3 颗爱心；每天一次，没有连续签到或漏玩惩罚。
- **宝物展示架**：在“我们的小屋 → 宝物收藏”里挑选最多 3 件已拥有的宝物，摆在小屋墙上的展示架；再次点击即可收起，刷新后保留。
- **照片纪念册**：在“我们的小屋 → 纪念册”里拍下当前场景，记录猫名、拍摄日期与穿搭。最多保存 8 张 JPEG，最长边 960 像素，每张编码后不超过 140,000 字符；可下载、删除，原有文字回忆也会保留。
- **轻柔奶喵**：圆润的短叫声、轻颤音和收尾滑音，区分开心、疑问、饿肚子和犯困的语气，并保留不同品种的声线。声音由浏览器实时合成，无需下载音频文件。

## 宠物外观与模型构建

猫、狗、兔使用独立的头脸和躯干造型。肩部、四肢与爪子连成一张蒙皮表面，由 14 根骨骼驱动；眼睑沿脸部曲面开合，保留虹膜形状，支持自然眨眼、半闭眼和亲近表情。长毛品种使用胸鬃与脸侧毛簇轮廓，搭配柔软的绒面材质。狗摇尾、兔跳跃与耳朵摆动、猫伸展和小宠物嗅探分别处理。

小屋中的“看近一点”会拉近并跟随宠物；“看看小屋”恢复房间视角。模型以 Meshopt 压缩的 GLB 按需加载，最近使用的六个模型保存在内存中。加载失败时使用本地造型生成器，存档和服饰接口保持兼容。

模型源在 `src/pet-anatomy.js` 与 `src/cat-model.js`，运行 `npm run assets:pets` 重新生成 `public/pets/`。预览图使用相同的材质和灯光生成：先启动开发服务器（例如 `npm run dev -- --port 4201`），再运行 `PET_STUDIO_URL=http://127.0.0.1:4201 npm run assets:portraits`。发布只构建应用，直接使用已检入的模型与预览图。

## 操作

首次进入时，选择猫咪、取好名字，再点击“带它回家”。

| 操作     | 方法                                                                                                           |
| -------- | -------------------------------------------------------------------------------------------------------------- |
| 走路     | 在小屋或探险场景中使用方向键、WASD、屏幕方向按钮，或点击地面                                                   |
| 转动视角 | 使用视角旋转按钮；领养与近景页面也可拖动场景                                                                   |
| 摸摸小猫 | 在小屋或衣柜中点击小猫                                                                                         |
| 近景陪伴 | 在“我们的小屋”中打开“近看小猫”，点小猫的头、下巴、鼻尖或爪子，也可使用五个互动按钮；拖动只转动视角，不触发互动 |
| 换装     | 打开“换衣服”，选择部位和服饰；再次点击已穿上的服饰即可脱下                                                     |
| 摆放家具 | 在“我们的小屋”中进入布置，选择家具并拖动摆放                                                                   |
| 开关音效 | 点击右上角的音符按钮                                                                                           |

## 存档

进度自动保存在当前浏览器的 `localStorage` 中，没有云端存档。不同浏览器、设备或站点地址之间不会自动同步；清除网站数据会删除本地进度。

- 设置中可以**导出 JSON 存档**，再到另一设备/浏览器导入。照片和展示架选择随存档一起转移；导入文件最大 3 MB，必须通过版本、数据和照片格式校验，并由你确认后才替换进度。
- 导入和“完全重新开始”都会先备份当前已领养的小猫；可用“恢复上一次进度”找回。这里只保留一份最近的备份，不能恢复已被浏览器清除的网站数据。
- 保存失败会持续显示警告，恢复成功后自动消失。照片容量不足时，相册也会提示尚未保存；**请在关闭页面前导出当前进度，或删除一些照片后重试**。
- 无法读取或版本不兼容的存档不会被新游戏自动覆盖。可以先导出原文件；明确确认重新开始时，原始内容会另存到 `miaow-cottage-v1-unreadable`。
- 存档无云同步，也不支持合并多个同时打开的游戏标签页，建议同一站点只开一个游戏页。

## 画质与性能

设置中可选择“标准”或“省电”，偏好会保存在本机。省电模式降低绘图分辨率和阴影贴图尺寸，不改变小猫模型和玩法。领养页使用预生成的静态预览图，不再现场构建 34 个模型，浴室、衣柜和户外场景在首次进入时才创建。弹窗打开或页面进入后台时暂停持续绘制，家具拖动写入合并处理，并在释放、取消、离开或切到后台时保存最终位置。

## 本地开发

推荐使用 Node.js 22 和 npm；游戏需要支持 WebGL 2 的现代浏览器。

```sh
git clone https://github.com/leeweir/cococat.git
cd cococat
npm ci
npm run dev
```

本地开发地址：<http://127.0.0.1:4175/>。

| 命令                           | 用途                                                          |
| ------------------------------ | ------------------------------------------------------------- |
| `npm run dev`                  | 启动开发服务器                                                |
| `npm test`                     | 运行 Node 单元与模型回归测试                                  |
| `npm run test:browser:install` | 安装 Playwright Chromium（首次运行浏览器测试前）              |
| `npm run test:e2e`             | 运行桌面与手机尺寸的隔离浏览器回归                            |
| `npm run test:e2e:smoke`       | 只运行桌面与手机的核心流程冒烟测试（共 2 项）                  |
| `npm run build`                | 构建生产版本到 `dist/`                                        |
| `npm run check`                | 依次运行测试和生产构建                                        |
| `npm run preview`              | 预览已构建的 `dist/`，地址为 <http://127.0.0.1:4175/cococat/> |

生产预览前先运行 `npm run build`。开发服务器与预览服务器使用同一端口，切换时请先停止正在运行的服务。

测试覆盖存档迁移/导入导出/失败保护、奖励去重、猫咪网格和步态、服饰搭配与资源释放、20 种猫咪的领口贴合与转头稳定性、书包贴合、家具布局和绕行路径、手动移动碰撞、每日心愿、展示架、照片校验和保存调度。

浏览器测试使用临时上下文和独立端口 **4198**，不会打开玩家的浏览器配置或真实存档；涵盖领养、照顾、换装重载、存档故障、惰性场景、画质、暂停恢复、家具写入、心愿和纪念册。也可使用本机 Chrome：`PLAYWRIGHT_CHANNEL=chrome npm run test:e2e`。失败截图与跟踪文件保存在 `test-results/`，不纳入版本控制。

## 代码组织

- `src/main.js`：场景切换、活动生命周期与状态提交。
- `src/care-view.js`、`wardrobe-view.js`、`exploration-view.js`：照顾、换装、探险的界面渲染及事件绑定；`ui-dom.js` 提供共用 DOM 与转义工具。
- `src/state.js`：兼容旧存档的状态、奖励与家具规则。
- `src/save-manager.js`、`save-ui.js`：存档校验、备份、导入导出与确认界面。
- `src/daily-wishes.js`、`photo-album.js`、`treasure-display.js`：每日心愿、照片记录及 3D 展示架。
- `src/performance.js`：画质设置与延迟保存；`world.js`、`living-world.js`：渲染、资源管理、移动与场景交互。

样式保留现有奶油色/草木绿视觉，基础控件、移动端布局、主题调整和新增功能均在 `src/style.css` 中按原有层叠顺序组织。

## 自动发布

源码和 GitHub Pages 使用同一个公开仓库 `leeweir/cococat`，无需独立发布仓库，也无需提交 `dist/`。

推送到 `main` 后，[Publish cococat](https://github.com/leeweir/cococat/actions/workflows/pages.yml) 工作流会安装依赖、运行 `npm run check`（全部单元测试及生产构建），通过后将构建产物部署到 GitHub Pages。自动和手动发布均不安装浏览器、不运行 E2E，以免共享运行器上的 3D 软件渲染拖慢发布。

发布前可在本地运行 `npm run test:e2e` 执行完整 28 项回归，或运行 `npm run test:e2e:smoke` 执行桌面与手机尺寸各 1 项核心流程测试，覆盖领养、喂食、换装、刷新后的存档保留及页面横向溢出。

E2E 与发布流程独立。若在其他 CI 环境中手动运行浏览器测试，首个用例重试后仍失败则立即停止，避免后续用例继续累计超时。

仓库 **Settings → Pages → Build and deployment → Source** 应选择 **GitHub Actions**。

生产资源路径在 `vite.config.js` 中设为 `/cococat/`，开发服务器使用根路径。发布地址为 <https://leeweir.github.io/cococat/>。
